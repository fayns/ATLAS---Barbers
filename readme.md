# ATLAS - Barbers

A bright, conversion-focused barbershop website concept for a freelance frontend portfolio.

## Concept

ATLAS is intentionally different from a luxury/editorial restaurant concept: brighter visual language, rounded cards, lime accent, statistics, team cards, FAQ and a booking-focused CTA flow.

This is a **fictional demo project**, not a client website.

## Features

- Responsive layout
- Distinct light / modern visual identity
- Service pricing cards
- Team showcase
- Studio / about section
- Online booking UI
- FAQ accordion
- Mobile navigation
- Scroll reveal animation
- Reduced-motion support
- No framework or build step

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
